# Cabinetry project inquiries

Use this skill when a user wants to start or discuss a custom cabinetry project with H & H Custom Cabinetry in the Greater Toronto and Hamilton Area (GTHA).

## Available actions

- Request a free quote using the official form: https://forms.gle/JT1WhXag7zr2zA6SA
- Request an appointment using the official calendar: https://calendar.app.google/NGs2aarphHbUTMZJ6
- Call the business: 289-643-3963
- Email the business: info@hhcustomcabinetry.ca
- Get directions to the showroom: https://g.page/r/Ca7gNl4WsWvhEBM/

## Important appointment rule

A calendar selection is only an appointment request. Never represent it as a confirmed booking. H & H Custom Cabinetry will contact the requester by email or phone to discuss their needs and confirm the exact date and time.

## Useful project details

When helping a user prepare an inquiry, suggest that they provide the room or cabinetry type, approximate dimensions, desired style, storage needs, preferred materials or colours, budget range, target timeline, and relevant photos. Do not invent requirements or submit any external form without the user's clear direction.
